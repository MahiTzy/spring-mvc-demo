# Spring MVC Demo

A Java web application demonstrating the Model–View–Controller pattern with Spring MVC.

## Overview
This repository provides a learning project for understanding request handling and the MVC architecture. The exact controllers, views, and configuration are defined by the source code.

## Technology
- Java
- Spring MVC
- Servlet container or runtime configured by the project
- Maven or the declared build tool

## Getting Started
1. Install a compatible JDK and the runtime required by the project.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/spring-mvc-demo.git
   cd spring-mvc-demo
   ```
3. Import the project into your Java IDE or build it using its configured build tool.
4. Configure the application server if required, then deploy and run the application.

## Application Flow
Review the controller mappings, model objects, and view templates to understand how requests are processed and responses are rendered.

## Development
Use the build configuration for dependency management and tests. Keep environment-specific settings outside committed source files.
